01Friend Groups

Your friends, in folders.

Group your friends right in the DM sidebar. Every folder gets an emoji and a colour, folds away when you don't need it, and takes people by drag and drop. Click anyone to open your DM.

  • Online count on every folder
  • What they're playing, or when they were last on
  • Unread badges, same as your DMs
  • Also a Groups tab on the Friends page

02Command Palette

Ctrl Shift K

One shortcut to turn any plugin on or off, switch plugin profiles, jump to a server, channel or DM, or reload Discord. No more digging through settings.

It works on this page too. Press it to search every section and plugin here.

  • Plugins, profiles, servers, channels and DMs in one list
  • Arrow keys and Enter, no mouse needed
  • Turn CommandPalette on once, change the shortcut if you like

03RenuxAI

Claude, in your chat.

/ai catchup tells you what you missed. Right-click any message to get it explained, summed up from there, translated or answered. Point it at an image and it describes it or pulls the text out.

It runs on your Claude Code login, so there's no API key to buy. An Anthropic API key works too, if you have one.

  • /ai ask, catchup, summarize, rewrite, translate
  • Answers only you can see, unless you choose to send them
  • Explain, reply, translate and read images from the right-click menu

04LinkSafety and SecretGuard

Catches the stuff you'd regret.

LinkSafety puts a warning under look-alike Discord, Steam and Roblox links before anyone clicks. SecretGuard stops you before you paste your token, a Roblox cookie, an API key or a card number into a chat.

  • Fake domains, look-alike letters, raw IPs, masked links
  • Free Nitro and free gift bait
  • Tokens, cookies, API keys, passwords, card numbers
  • Nothing gets blocked. It just asks first

05RenuxBridge

Let Claude Code build your server.

RenuxBridge hooks your Discord up to Claude Code over MCP. Describe the server you want and it gets built: roles in the right order, private categories, voice lobbies, permissions and all.

  • One request can lay out a whole server
  • Only listens on your own PC, behind a token
  • Never touches your DMs
  • Deleting stays off until you switch it on
  • Setup: turn it on, copy the command from its settings, run it once

06Custom plugins

Write your own.

Drop a .js file into %APPDATA%\Renuxcord\plugins and it loads with Discord, with the same powers as the built-in plugins: patches, slash commands, menus and settings. The folder comes with a README and a working example.

  • Reload with Ctrl+R, nothing to build
  • Rename a file to _Name.js to switch it off
  • Only add plugins you wrote or trust

    Install on Windows

    Up and running in a minute.

    1. 01

      Download the installer

      RenuxcordInstaller.exe from the latest release. It's tiny because it downloads the newest build when you run it.

    2. 02

      Get past SmartScreen

      The installer isn't code-signed yet, so Windows may say it protected your PC. Click More info › Run anyway. It's built from the source on GitHub.

    3. 03

      Pick your Discord

      Choose Stable, PTB or Canary and press Install / Repair. Discord restarts with Renuxcord in it.

    4. 04

      Switch plugins on

      Settings › Renuxcord › Plugins. Turn on CommandPalette and Ctrl Shift K gets you to the rest.

    Needs
    Windows 10 or 11 and the Discord desktop app: Stable, PTB or Canary.
    Updates
    Renuxcord updates itself, and puts itself back after Discord updates.
    Uninstall
    Run the installer again and press Uninstall. Your settings stay in %APPDATA%\Renuxcord.

    Everywhere else

    Same plugins on your Mac, Linux box and phone.

    macOS and Linux

    Get the installer for macOS or Linux, open it, pick your Discord and press Install. Renuxcord keeps itself updated from then on.

    Mac: the first time, macOS blocks apps from outside the App Store. Open System Settings › Privacy & Security and press Open Anyway. If it says macOS blocked changes to Discord, turn the installer on under App Management. Linux: extract the download and double-click RenuxcordInstaller.

    Rather use a terminal? This does the same:

    curl -fsSL https://github.com/Renuxchan/Renuxcord/releases/download/devbuild/install.sh | sh

    Android

    Install Renuxcord.apk. It opens Discord with Renuxcord loaded, updates Renuxcord by itself and has its own page in Discord's settings.

    Android 8 or newer. Allow installing from your browser when Android asks.

    iPhone and iPad

    Sideload Renuxcord.ipa with SideStore, AltStore, Sideloadly or TrollStore.

    No sideloading? Get the free Userscripts app, add Renuxcord.user.js and open discord.com in Safari.

    FAQ

    Things people ask.

    Windows says "Windows protected your PC"

    The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info › Run anyway. The source it's built from is on GitHub.

    Discord voice doesn't work where I live

    In places like the UAE, Discord's text works but voice calls get blocked. Turn on the Drover plugin on Windows: it sets up hdrover's Discord Drover for you, which gets voice through without a VPN. It can also send Discord through an HTTP or SOCKS5 proxy.

    Do the phone apps have every plugin?

    Nearly. They run Discord's web app with Renuxcord in it, so the plugins that need a computer (the AI bridge, files on your PC, Drover) stay on desktop.

    Do I need an API key for /ai?

    No. RenuxAI uses your Claude Code login if you're signed in to Claude Code on the same PC. An Anthropic API key works too, if you'd rather use one.

    Will Discord updates break it?

    Renuxcord puts itself back after Discord updates, and fixes for Discord changes get pulled in and released automatically.

    Does it keep my settings from another client mod?

    If you're coming from the client mod Renuxcord is built on, yes. The first time it starts, it copies your settings, QuickCSS and themes over.

    Is it allowed?

    Client mods are against Discord's Terms of Service. Lots of people use them anyway, but it's at your own risk.

    Mac or Linux?

    The installer is Windows only for now. Renuxcord itself runs on macOS and Linux if you build it from source. The steps are on GitHub.

    How do I uninstall?

    Run the installer again and press Uninstall. Discord goes back to normal, and your Renuxcord settings stay in %APPDATA%\Renuxcord.
