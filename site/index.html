      05Download

      Get it on whatever you've got.

      One installer per computer, one app per phone. After that, Renuxcord updates itself.

      Download for WindowsRenuxcordInstaller.exe
      1. Run the installer. It's tiny because it downloads the newest build when it runs.
      2. Get past SmartScreen. It isn't code-signed yet, so Windows may say it protected your PC. Click More info › Run anyway.
      3. Pick your Discord (Stable, PTB or Canary) and press Install / Repair. Discord restarts with Renuxcord in it.
      4. Switch plugins on in Settings › Renuxcord › Plugins, or turn on CommandPalette and press Ctrl+Shift+K.

      Windows 10 or 11. To uninstall, run the installer again and press Uninstall. Your settings stay in %APPDATA%\Renuxcord.

      Download for macOSApple silicon and Intel
      1. Open the zip and run Renuxcord Installer.
      2. Let it open. It isn't notarized, so the first time macOS blocks it. Open System Settings › Privacy & Security and press Open Anyway.
      3. Pick your Discord and press Install / Repair. If macOS says it blocked changes to Discord, turn the installer on under App Management and press Install again.

      Rather use a terminal? This does the same:

      curl -fsSL https://github.com/Renuxchan/Renuxcord/releases/download/devbuild/install.sh | sh

      Run it again after Discord itself updates. Settings live in ~/Library/Application Support/Renuxcord.

      Download .debUbuntu, Debian, Mint Download .rpmFedora, openSUSE
      1. Install the package like any app, then start Renuxcord Installer from your apps. Anything else? Get the .tar.gz.
      2. Pick your Discord and press Install / Repair. It finds the normal download, .deb, .rpm, tar.gz and Flatpak installs. Snap isn't supported.

      Or one line in a terminal:

      curl -fsSL https://github.com/Renuxchan/Renuxcord/releases/download/devbuild/install.sh | sh

      sh -s -- uninstall takes it out again. Settings live in ~/.config/Renuxcord.

      Download Renuxcord.apkAndroid 8 or newer
      1. Open the APK and allow installing from your browser when Android asks.
      2. Log in to Discord in the app. You get Discord's full app in a phone layout: calls, Server Discovery and every menu (hold anything to open its menu).
      3. That's it. Swipe or press back to get from a chat to your servers. Notifications keep coming in the background, and Renuxcord updates itself.

      The phone apps run Discord's full web app with Renuxcord in it, so only the few plugins that need a computer (the AI bridge, files on your PC, the voice unblocker) stay on desktop.

      Open this page on your iPhone or iPad and tap the app you sideload with:

      Add to SideStore Add to AltStore Install with TrollStore
      1. SideStore and AltStore add the Renuxcord source and keep the app updated by themselves.
      2. Sideloadly or something else? Get Renuxcord.ipa .
      3. No sideloading at all? Install the free Userscripts app from the App Store, add Renuxcord.user.js and open discord.com in Safari.

      iOS 15 or newer. Calls, Server Discovery and hold-to-open menus work inside the app. iOS only lets notifications through while the app is open or in a call.

      07FAQ

      Things people ask.

      Is it free? What's the catch?

      Free, no account, no ads, no catch. The whole thing is open source under GPL-3.0, so anyone can read exactly what it does.

      Windows says "Windows protected your PC"

      The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info › Run anyway. It's built from the source on GitHub by GitHub's own build machines.

      Discord voice doesn't work where I live

      In places like the UAE, Discord's text works but voice calls get blocked. Turn on VoiceChatUnblocker on Windows, macOS or Linux. Renuxcord sends voice through a tiny relay that starts every connection with decoy packets, so the network can't tell it's Discord voice, and it switches tricks by itself until one gets through. No VPN.

      Do I need an API key for /ai?

      No. RenuxAI uses your Claude Code login if you're signed in to Claude Code on the same computer. An Anthropic API key works too, if you'd rather use one.

      What's the Renuxcord badge, and why is there a tag in my About Me?

      Everyone using Renuxcord gets a Renuxcord User badge on their profile, and Renuxcord users see each other's. It works through an invisible tag Renuxcord adds to the end of your About Me. People without Renuxcord can't see the tag, and the badge is always on.

      Do the phone apps have every plugin?

      Nearly, and it's Discord's full app: voice and video calls, Server Discovery, and every menu (hold anything to open its menu). Only the plugins that need a computer (the AI bridge, files on your PC, the voice unblocker) stay on desktop.

      Will Discord updates break it?

      Renuxcord puts itself back after Discord updates. Fixes for Discord's changes get merged in every 6 hours, built, and delivered by the updater.

      Does it keep my settings from another client mod?

      If you're coming from the client mod Renuxcord is built on, yes. The first time it starts, it copies your settings, QuickCSS and themes over.

      Is it allowed?

      Client mods are against Discord's Terms of Service. Lots of people use them anyway, but it's at your own risk.

      How do I uninstall?

      Run the installer again and press Uninstall. Discord goes back to normal, and your Renuxcord settings stay where they are in case you come back. On Linux and macOS, the terminal command takes uninstall too.
