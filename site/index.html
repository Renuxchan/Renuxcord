Let AI build your Discord

Renuxcord's bridge connects your Discord to Claude Code over MCP. Create servers, roles, channels, permissions and whole layouts by just asking.

  1. Turn on RenuxBridge in Settings › Renuxcord › Plugins.
  2. Press Copy command in its settings and run it once in a terminal.
  3. Open Claude Code and ask for what you want.

Local only (127.0.0.1), token-protected, never touches DMs, deleting is off until you allow it.

claude
> make me a server called Night Shift for my valorant team.
  roles for coach, players and subs, a private staff area,
  voice lobbies and a rules channel

● create_server  Night Shift · 4 roles · 3 categories · 11 channels
● create_invite  discord.gg/nightshift · 7 days

  channels are hidden from everyone else, and #rules has
  your rules posted.

Write your own plugins

Every .js file in %APPDATA%\Renuxcord\plugins loads before Discord does, so it can patch, add slash commands, menus, settings and more. The folder comes with a README and a working example.

Open it from Settings › Renuxcord › Custom Plugins. Only add plugins you trust. 

const { definePlugin, CommandOptionType } = Renuxcord;

module.exports = definePlugin({
    name: "Hello",
    description: "Adds /hello",
    commands: [{
        name: "hello",
        description: "Say hi",
        execute(args, ctx) {
            Renuxcord.Api.Commands.sendBotMessage(
                ctx.channel.id, { content: "Hello! 👋" });
        }
    }]
});

FAQ

Windows says "Windows protected your PC"

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info › Run anyway. The source code it's built from is on GitHub.

Does it keep my settings from another client mod?

Yes. The first time Renuxcord starts it copies your existing settings, QuickCSS and themes over.

How do I uninstall?

Run the installer again and press Uninstall. Discord goes back to normal and your Renuxcord settings stay in %APPDATA%\Renuxcord.

Will Discord updates break it?

Renuxcord re-applies itself after Discord updates, and fixes for Discord changes are pulled in and released automatically.

Is it allowed?

Client mods are against Discord's Terms of Service. Plenty of people use them, but it's at your own risk.

Mac or Linux?

The installer is Windows-only for now. Renuxcord itself runs on macOS and Linux if you build it from source (instructions on GitHub).
